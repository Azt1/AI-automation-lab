# Como registrar uma entrega

Para manter um histórico claro e útil:

1. Escolha uma tarefa pequena do roadmap ou uma melhoria necessária.
2. Faça a alteração e valide o resultado.
3. Atualize `docs/progress-log.md` apenas com o que foi concluído.
4. Crie um commit objetivo, por exemplo: `feat: add document upload endpoint`.
5. Envie para a branch `main`.

## Prefixos de commit

- `feat:` nova funcionalidade
- `fix:` correção de comportamento
- `docs:` documentação
- `test:` testes
- `chore:` manutenção ou configuração
