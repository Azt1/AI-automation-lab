# Roadmap

Este roadmap é um guia de aprendizado e entrega. As etapas só serão marcadas como concluídas depois de implementadas.

## Fase 1 — Fundamentos

- [x] Criar e publicar a estrutura do repositório.
- [x] Definir foco de carreira: IA e Automação.
- [ ] Configurar ambiente Python e qualidade de código.
- [x] Criar o módulo inicial de análise de texto documental.
- [ ] Criar a primeira API com FastAPI.
- [ ] Adicionar testes automatizados e integração contínua.

## Fase 2 — Projeto 1: AI Document Processor

- [ ] Criar endpoint para receber documentos.
- [ ] Extrair texto de PDF e imagens com OCR.
- [ ] Usar IA para estruturar os dados extraídos.
- [ ] Criar interface para revisão humana.
- [ ] Registrar histórico e status de processamento.
- [ ] Publicar uma demonstração.

## Fase 3 — Automação de fluxos

- [ ] Integrar eventos com webhooks.
- [ ] Criar fluxo automático de processamento e notificação.
- [ ] Adicionar monitoramento, logs e tratamento de falhas.

## Critério de conclusão

Uma funcionalidade é considerada concluída quando tem código funcional, explicação no README e validação compatível com seu risco.
